# Crisis Response Social Media Automation App

## 🌟 Overview

A comprehensive Python application built using the Blackbox API to generate and schedule social media content for post-natural catastrophe job postings and resource allocation. This application demonstrates a complete end-to-end flow from crisis event creation to automated social media management.

## 🎯 Key Features

### ✅ **Functional End-to-End Flow**
- **Prompt → Media → Post**: Complete automation from crisis input to published content
- **Crisis Event Management**: Create and track natural disaster events
- **Job Posting Generation**: Automated job posting creation for emergency response
- **Content Generation**: AI-powered social media content using Blackbox API
- **Multi-Platform Publishing**: Simultaneous posting across Twitter, Facebook, LinkedIn, Instagram

## 🏗️ Architecture

### **Core Components**

1. **BlackboxAPIClient**: Handles AI content generation and image creation
2. **DatabaseManager**: SQLite-based data persistence with crisis events, job postings, and analytics
3. **SocialMediaManager**: Multi-platform posting and engagement tracking
4. **ResponseHandler**: Automated response system for user interactions
5. **AnalyticsManager**: Performance tracking and visualization
6. **CrisisResponseApp**: Main orchestration layer

### **Data Models**

- **CrisisEvent**: Natural disaster event tracking
- **JobPosting**: Emergency job position management
- **SocialMediaPost**: Platform-specific content management
- **UserProfile**: Targeted profile management
- **Analytics**: Performance metrics storage
